
# Release 2.1.74 (2026-11-14)

## Bug fixes

- **stage each language's test and audit reports for CI evidence (#1218)**
* fix(ci): stage each language's test and audit reports for CI evidence

ci-audit staged only Python's pip-audit.json and licenses.json, so a Rust audit leg uploaded no cargo-deny.json and the release-time evidence gate refused the audit gate as an empty payload. The new ci/evidence/reports action holds the one per-language report contract (python and rust; test and audit), stages a leg's declared reports version-suffixed, and fails a leg whose gate passed but wrote a report missing or empty, or whose language has no contract. ci-test and ci-audit stage through it and take the emit step's tools from it. Ref #1211.

- **keep a released site's default version on a develop deploy (#1219)**
* fix(docs-deploy): keep a released site's default version on a develop deploy

The develop deploy guarded set-default dev with a grep for a [default] marker in mike list, but mike never prints one: it records the default only as the root index.html that set-default writes, so the guard never matched and every develop deploy reset a released site's default to dev. The guard now asks whether a version carries the latest alias (mike list --json) and sets dev as the default only when none does; a failing mike list fails the deploy. The step's logic moves to deploy.sh, and default.test.sh, run by smoke-cd-docs.yml, checks it with the real mike. Ref #1214
