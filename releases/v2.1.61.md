## Features

- **skip the toolchain install in a managed package toolchain image (#1115)**
actions/package/setup now detects /etc/vergil/package-toolchain. When present, the OS prerequisites, uv and nFPM installs are skipped and check-toolchain.sh verifies every listed tool against the marker, failing with ::error:: on a missing or mismatched tool, a missing nfpm when nFPM is needed, or an empty or malformed marker. Without the marker the raw-image path is unchanged. Adds the framework-free harness check-toolchain.test.sh, runs it in the setup smoke workflow, and documents the marker contract. Ref vergil-project/vergil-actions#1088.
