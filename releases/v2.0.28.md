
# Release 2.0.28 (2026-06-02)

## CI

- **add build-only docs verification to PR CI**
Add a reusable ci-docs.yml workflow that stages the docs the same way the CD docs deploy does and runs mkdocs build --strict — build only, no mike, no push, no credentials. Documentation that fails to build is now caught pre-merge as a CI gate instead of post-merge in the CD docs job.

Factor the changelog/release-notes staging and nav patching into a shared actions/shared/docs/stage composite action used by both ci-docs and cd/docs/deploy, so CI and CD build the docs identically and a green CI docs check predicts a green CD deploy. The deploy action no longer stages inline; cd-docs.yml runs the shared stage step before deploy.

The CI workflow self-guards on mkdocs config presence so repos without docs are unaffected, and is wired into this repo's own ci.yml on the default prod container for parity with the cd-docs deploy.
