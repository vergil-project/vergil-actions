
# Release 2.1.75 (2026-11-15)

## Bug fixes

- **run the action test suites in vrg-validate (#1224)**
* fix(tests): run the action test suites in vrg-validate

validate-custom now runs every tracked actions/**/tests/*.test.sh suite from the repo root, so local validation exercises the action harnesses CI runs. Suites that reach a live service, or need a tool the validation image lacks, are listed in CI_ONLY_ACTION_SUITES with a reason and skipped by name; a stale entry fails the run. Tests of the runner are in scripts/tests/action-suites-run.test.sh. Ref vergil-project/vergil-actions#1108

* fixup! fix(tests): run the action test suites in vrg-validate

* fix(tests): run live-check.test.sh in vrg-validate

live-check.test.sh uses a fake curl and a fixture tree, reaches no live service, and passes in the validation image, so validation runs it too (ruling N0.1 on #1108).

* fix(tests): keep action suites off the loop's stdin in vrg-validate

- **name the security gate's scanners in its evidence tools (#1226)**
* fix(ci-security): name the security gate's scanners in its evidence tools

The security gate's evidence.json had an empty tools list beside its CodeQL, Semgrep and Trivy SARIF reports. The evidence job now names trivy and semgrep, and codeql when its job passed. A new harness, security-tools.test.sh, run from smoke-setup-vergil, checks every scanner partial is named. Ref #1215.

* fix(validate): leave security-tools.test.sh to CI, which has yq


## CI

- **bound build-index with a 60-minute timeout (#1225)**
build-index had no timeout-minutes, so a hung index build ran to GitHub's 6-hour default. Cap it at 60 minutes, matching vergil-tooling's package-index wait, with a comment to lower it once epic vergil-project/.github#1003 ships.


## Documentation

- **name prod-base as the validation image and use vrg-container-docs (#1104)**
For a repo with no primary language vrg-container-run uses prod-base, not dev-base. vrg-container-run publishes no port, so the docs preview goes through vrg-container-docs.
