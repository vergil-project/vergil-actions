## Features

- **fail fast when the deployed package index is not the one just built (#1125)**
* feat(publish-index): fail fast when the deployed package index is not the one just built

build-index records the sha256 of every signed InRelease and repomd.xml it built (the new publish/index/live-check action, mode: manifest) as a job output. After actions/deploy-pages, the deploy job fetches each file from the deployment's page_url with a cache-busting query until all match, and fails with an ::error:: naming the run and what was served after about five minutes (vergil-project/packages#46). The script has a framework-free harness, run by the new smoke-publish-index workflow.


## Refactoring

- **require a package toolchain image (#1124)**
* refactor(package): require a package toolchain image

actions/package/setup no longer installs OS prerequisites, uv or nFPM. check-toolchain.sh runs unconditionally, so a raw image fails with '::error::package jobs require a vergil package toolchain image; /etc/vergil/package-toolchain not found'. It also fails with one ::error:: per required tool (uv, curl, git, gpg, tar, gzip) the marker leaves out; nfpm stays required only with --nfpm. Deletes os-prereqs.sh and its harness, drops the harness from the setup smoke workflow, and updates the docs. Ref vergil-project/vergil-actions#1090.
