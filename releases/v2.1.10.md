## Features

- **add reusable ops-epic-sweep reconciliation workflow (#742)**
* feat(workflows): add reusable ops-epic-sweep reconciliation workflow

Reusable workflow (on: workflow_call) that runs vrg-epic-audit --close to reconcile epic/task drift — catching any epic/task that missed its event-driven close. Mints an org-wide app token (no repositories input) since the sweep closes drifted tasks across code repos and rolled-up epics in .github; sets VRG_EPIC_SWEEP=1 to authorize the automated close (vergil-tooling #2104). A scheduled caller per org (task #2105) drives it. Part of epic vergil-project/.github#80.

* fix(workflows): pass window-days via env to avoid semgrep run-shell-injection

The semgrep run-shell-injection rule flags interpolating a workflow_call input directly in a run: step (caller-controlled). Move inputs.window-days into a WINDOW_DAYS env var and reference "$WINDOW_DAYS" in the shell, per the rule's remediation. Part of epic vergil-project/.github#80.
