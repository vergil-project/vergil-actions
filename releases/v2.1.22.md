
# Release 2.1.22 (2026-08-10)

## Features

- **install declared [container].system-packages on CI test jobs (#808)**
* feat(ci): install declared system-packages on CI test jobs

Add actions/shared/setup/system-packages composite action: reads the declared [container].system-packages via vrg-container-system-packages --install-script and apt-installs them with bounded retry (mirror-flake tolerance) and fail-closed behaviour (a missing candidate exhausts retries and exits non-zero with the speller's package+platform message). The retry/fail-closed loop lives in install.sh so it is unit-testable; action.yml is a thin wrapper. Wired into the unit job of ci-test.yml after Install vergil-tooling — test-runtime only, not lint/typecheck (spec 3.3). Epic vergil-project/.github#272.

* test(ci): cover system-packages install retry and fail-closed paths

Self-contained, framework-free harness (this repo declares language=shell, which runs no test gate and ships no action-test convention) for install.sh: PATH-stubs vrg-container-system-packages and apt-get to exercise the installable happy path, the fail-closed bogus-package path (non-zero exit with the 'not installable' message), the transient-flake retry-then-success path, and the no-packages skip. Epic vergil-project/.github#272.
