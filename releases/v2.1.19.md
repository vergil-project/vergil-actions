
# Release 2.1.19 (2026-08-04)

## Features

- **route C++ CI to compiler-family images with per-kind cardinality (#793)**
Extend the reusable ci-*.yml workflows to accept language: cpp and run the C++ pipeline per compiler-family image.

A new actions/ci/matrix composite action resolves the per-version job matrix from the flat versions input: for cpp it splits each clang-/gcc- token and routes it to prod-cpp-clang:<n> / prod-cpp-gcc:<n>, and it emits an 'all' matrix (per-version) plus a 'once' matrix collapsed to the primary version. ci-quality/ci-test/ci-audit gain a matrix prep job and consume all (typecheck, unit) or once (lint, dependencies) so the emitted job/gate names line up exactly with github_config.desired_ci_gates_ruleset for a cpp repo: per-version typecheck/test, run-once lint/audit keyed to the primary clang tag. Non-cpp languages resolve byte-identical images and keep per-version cardinality.

ci-security wires Semgrep p/c and p/cpp for cpp via extra-config (C++ has no single p/<language> ruleset); CodeQL already forwards the cpp language and cpp is CodeQL-supported. Adds a C++ example to the workflow README.
