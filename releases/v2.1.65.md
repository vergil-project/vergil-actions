
# Release 2.1.65 (2026-11-11)

## Bug fixes

- **install the newest release of the pinned line for install-source git (#1145)**
publish-index's build-index job installed vergil-tooling at the floating vX.Y tag. A release dispatches the index rebuild before it moves vX.Y, so the rebuild ran the previous release's tooling. With install-source: git and a line pin, the setup action now lists the line's vX.Y.Z tags with git ls-remote and installs the newest one; a failed lookup or an empty line fails the job rather than falling back to vX.Y. Per the human's decision, the release order and the promote stage are unchanged, and the auto install path keeps the floating tag. Ref #1144.
