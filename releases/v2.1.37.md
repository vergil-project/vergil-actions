
# Release 2.1.37 (2026-10-06)

## Features

- **ci-package reusable workflow and package toolchain setup (#904) (#907)**
Add actions/package/setup (OS prerequisites via apt-get or dnf, sha256-pinned uv 0.12.23 installer, vergil-tooling from the checkout or [dependencies].vergil, sha256-pinned nFPM 2.47.0) with a detect.sh harness wired into the smoke workflow, and .github/workflows/ci-package.yml (matrix, build and install-test per cell, package evidence gate). Document the package gate in the emit action. Epic vergil-project/.github#356, plan task A1.

- **publish-index reusable workflow (#906) (#908)**
Add the publish-index reusable workflow: build-index (index-signing environment, vrg-package index) then deploy to GitHub Pages, serialized by the publish-index concurrency group. Document it in the reusable workflows overview.

- **cd-release: package build, main-only signing job, attach, dispatch (#905) (#909)**
Packaged repos build their .deb/.rpm cells, sign the rpms in the main-only package-signing environment, attest and attach them with packages-manifest.json, and dispatch package-released to <owner>/packages. Repos without [package] keep today's release behavior.
