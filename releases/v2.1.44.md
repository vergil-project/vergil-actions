
# Release 2.1.44 (2026-10-19)

## Features

- **run the finished-branch sweep nightly in every repo (#955)**
* feat(ops): add branch-sweep action that reports deleted branches in the job summary

Wraps vrg-branch-sweep --apply. Deleted branches of merged PRs, which mean GitHub skipped its after-merge processing, get a warning block and ::warning:: annotations. The step fails when the sweep fails or its output cannot be reconciled with its summary line. Covered by a framework-free harness run by smoke-branch-sweep.yml. Refs #952.

* feat(ops): run the finished-branch sweep nightly from ops-github-config

Adds a branch-sweep job to the reusable workflow every consumer's ops.yml already calls, so every repo is swept with no consumer change. Uses a GitHub App token scoped to the calling repo with only contents:write and pull-requests:read. Refs #952.

* docs(ops): document the branch-sweep action
