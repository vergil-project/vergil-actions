
# Release 2.1.17 (2026-07-13)

## Refactoring

- **share one harvest across evidence gate and attach (#782)**
Rewire the cd-release CI-evidence gate and attach composites to share a single artifact harvest instead of each running the atomic `bundle` (which re-downloaded the release PR's artifacts).

The gate now calls `vrg-ci-evidence harvest` (network download + validate_completeness gate), persisting the downloaded evidence and harvest-state.json into a shared staging dir on the job workspace (${{ github.workspace }}/.ci-evidence-staging). The attach now calls `vrg-ci-evidence assemble --staging <same-dir>`, which is fully network-free and produces the tarball + standalone manifest offline. Both composites run in the same cd-release job, so the workspace filesystem persists between them and the release's artifacts are downloaded exactly once.

Warning-mode wrappers and the enforce flag are preserved exactly in both steps; the attest and gh release upload steps are unchanged. Part 2 of the double-harvest fix (Part 1 is the vergil-tooling CLI split, #2330).
