
# Release 2.1.51 (2026-10-22)

## Bug fixes

- **make detect.sh ignore the repo's uv settings with uv run --no-config (#1010)**
detect.sh read vergil.toml with uv run --no-project --python 3.14, which still reads the repo's uv settings ([tool.uv] in pyproject.toml, uv.toml) from the working directory. In a repo that sets python-downloads = "manual" (with python-preference = "only-managed") it failed in the package images, which ship no Python and need uv to download one. It now runs uv run --no-config --no-project, so the repo's uv settings cannot reach it. detect.test.sh gains cases that run detect.sh from inside a fixture repo with those settings in pyproject.toml and in uv.toml, with an empty managed-Python dir, and assert the same install spec. The pin.test.sh source guard no longer exempts detect.sh outright: it is now a config-free file whose every uv command must pass --no-config, with fixtures both ways. Ref vergil-project/vergil-actions#1003
