# Release 2.1.87 (2026-11-19)

## Bug fixes

- **pin uv 0.13.9 and require a released Python 3.15 for vergil-tooling (#1333)**
  uv 0.12.23 resolved --python 3.15 --managed-python to cpython-3.15.0rc3 on host runners, while the images' uv gave 3.15.2. Bump the pinned uv and its hashes to 0.13.9 (verified against the release's .sha256 files; its managed list offers 3.15.2), and fail the install when the tool environment, or the self repo's host sync, runs on anything but a released 3.15, logging the version it found.

  Ref vergil-project/vergil-actions#1331
