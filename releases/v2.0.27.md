
# Release 2.0.27 (2026-06-01)

## Bug fixes

- **run codeql on bare runner so autobuild has a language toolchain**
Commit 4d942b5b moved the codeql job into the prod-base container to silence 'uv: command not found' (ref #636), but prod-base ships no language toolchain. CodeQL autobuild for compiled languages (go, java, rust) needs the compiler on PATH, so it failed fleet-wide with 'go: executable file not found in $PATH' on every consuming repo pinned to @v2.0.

Language images are published per-version only (prod-go:1.25, prod-go:1.26) with no prod-<lang>:latest tag, and a job-level container directive cannot resolve a concrete version inline, so the language-container route is a dead end. The uv concern that motivated the container was independently handled ~45 min later in setup/vergil (84bf315e, fd62605c), which now installs uv on bare runners.

Dropping the container restores the pre-regression bare-runner execution that passed CodeQL on 2026-05-27. The runner supplies every language toolchain autobuild needs; setup/vergil supplies uv for vrg-sarif-evaluate.
