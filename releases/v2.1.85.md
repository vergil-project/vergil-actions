# Release 2.1.85 (2026-11-19)

## Features

- **install vergil-tooling from one release commit with uv (#1320)**
  * feat(setup-vergil): install vergil-tooling from one release commit with uv

  The setup action drops the packaged install and the vergil apt repository bootstrap. A released ref resolves once with git ls-remote to the peeled commit of one vX.Y.Z tag and installs that commit with uv tool install, constrained by its own uv.lock fetched over git; a dev ref installs unconstrained. Every install passes --no-config and --python 3.15 --managed-python with UV_PYTHON, UV_PYTHON_PREFERENCE and UV_NO_MANAGED_PYTHON unset, uses the image's VERGIL_CORE_PYTHON_DIR with downloads off when set, and checks that vrg-whoami runs from uv's tool bin directory, which is added to GITHUB_PATH. Ref vergil-project/vergil-actions#1317.

- **install the driver vergil-tooling from one release commit (#1321)**
  * feat(package-setup): install the driver vergil-tooling from one release commit

  detect.sh resolves a line or exact pin to its release tag and that tag's commit SHA with one git ls-remote (the peeled entry, since release tags are annotated), prints a spec naming the SHA, and writes the commit's uv.lock, exported from a shallow fetch, as constraints. Dev refs and the self repo install unconstrained. The install step passes --force --no-config --managed-python with the python input, clears UV_PYTHON, UV_PYTHON_PREFERENCE and UV_NO_MANAGED_PYTHON, and checks that vrg-whoami resolves to uv's tool bin dir and runs. Ref vergil-project/vergil-actions#1318

- **push release tags with the automation App token (#1322)**
  * feat(release): push release tags with the automation App token

  tag-and-release takes a required tag-token input and pushes the release tag, the develop changelog tag and the missing-objects resync through push-tag.sh, which replaces the checkout's Authorization header with the App token's. cd-release checks both App secrets and mints a Contents-write token scoped to the repository before the evidence gate, the registry publish and the tag, failing with an error that names any missing secret; the secrets stay declared optional. vergil-actions' own cd.yml passes its App token. Ref vergil-project/vergil-actions#1315
