# Release 2.1.97 (2026-11-24)

## Bug fixes

- **refuse an empty App key input by name before the token mint (#1434)**
  A composite action's required: true does not reject an empty string, so an empty app-client-id or app-private-key reached actions/create-github-app-token and failed there without naming the input or the automation environment. A new step after the ref guard fails first, naming each empty input; the keys reach it only through env, and there is no GITHUB_TOKEN fallback. ops-report-inputs.test.sh checks the step's place and env and runs it with each key empty, both, both unset and both set. Ref #1432.
