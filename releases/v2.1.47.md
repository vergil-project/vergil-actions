
# Release 2.1.47 (2026-10-21)

## Bug fixes

- **emit a clear error when vergil.toml or [dependencies].vergil is missing (#982)**
A missing vergil.toml, or one without [dependencies].vergil, crashed the install step with a Python traceback; the intended ::error:: annotation only fired for an empty string. The pin is now read by read-pin.sh, which fails with a single ::error:: naming the file or key and saying what to add for a missing file, missing table or key, empty or non-string value, or invalid TOML. derive.sh gets the same handling for a missing or invalid vergil.toml. Both are covered by framework-free harnesses run in the smoke-setup-vergil workflow. Ref #977.
