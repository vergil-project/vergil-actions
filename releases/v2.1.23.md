## Features

- **TypeScript support in reusable workflows (#815)**
Accept language: typescript in the reusable CI workflows.

- Matrix routing: node-<major> version tokens resolve to prod-ts-node:<major>
  images (ts-node suffix + numeric tag), mirroring C++ token routing. Extracted
  the resolver to actions/ci/matrix/resolve.sh with a unit test.
- Cardinality: TYPECHECK/LINT/AUDIT run once (collapsed to the primary Node
  version via the matrix once output); only TEST fans out per Node version. The
  typecheck job now consumes once for TypeScript, matching the run-once gates
  desired_ci_gates_ruleset keys to ci.versions[0].
- CodeQL mapping: primary-language typescript maps to javascript-typescript and
  cpp maps to c-cpp via one table in actions/ci/security/codeql/resolve-language.sh
  (bare typescript is not a valid CodeQL analysis language). Unit-tested.
- Semgrep: wire p/typescript for TypeScript repos.
