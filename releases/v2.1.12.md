
# Release 2.1.12 (2026-07-07)

## Bug fixes

- **fully-qualify the nested cd-docs reusable ref (#751) (#752)**
cd-docs-refresh is a reusable workflow called cross-repo, but it nested cd-docs.yml via a relative './.github/workflows/cd-docs.yml' — which does not resolve when the outer workflow is invoked from another repo via a tag (GitHub reports 'workflow was not found'), and which vrg-freeze-refs never pins. Make it a fully-qualified '@develop' ref so it resolves cross-repo and the release freeze rewrites it to the release tag. Fixes the org docs repos' daily cd-docs-refresh startup failure.
