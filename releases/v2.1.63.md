## Features

- **add a container-prefix input to ci-package.yml (#1133)**
* feat(package): add a container-prefix input to ci-package.yml

The matrix job's new images step rewrites the ghcr.io/vergil-project/prod-pkg- start of each cell's image in the vrg-package matrix build and test outputs to <prefix>-pkg-, logs the image each cell will use, passes the outputs on unchanged with the default prod, and fails on any other prefix or a missing or malformed output. package-runtime.test.sh now takes the matrix job's output step per workflow. Ref #1132

* test(package): test ci-package.yml's container-prefix input

package-image-prefix.test.sh checks the input declaration and the images step's wiring, then runs the step's own script for prod (byte-for-byte passthrough), an empty value, dev (only the image prefix changes) and refused prefixes and outputs. smoke-cd-release.yml runs it. Ref #1132
