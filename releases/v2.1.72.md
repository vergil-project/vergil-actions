
# Release 2.1.72 (2026-11-14)

## Bug fixes

- **set VRG_AUTOMATION_APP only on the github-config update step (#1194)**
* fix(ops): set VRG_AUTOMATION_APP only on the github-config update step

VRG_AUTOMATION_APP says the process holds the automation App's token, so vrg-whoami verifies GH_TOKEN whenever it is set. v2.1.71 set it on the whole github-config job, so the setup action's vrg-whoami --mode check ran with it and no GH_TOKEN, and every run failed. The variable now rides only on the update step, beside the App token; the develop-and-variable precheck reads it as AUTOMATION_APP. A new automation-env.test.sh harness, run from smoke-setup-vergil, keeps every workflow to this. Ref #1192

* test(ops): mark the yq variable in automation-env.test.sh for shellcheck
