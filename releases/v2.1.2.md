
# Release 2.1.2 (2026-06-05)

## Bug fixes

- **gate follows release-model instead of run-release wiring**
Make ci-version-bump.yml self-guard on the consuming repo's
vergil.toml: when release-model is "none" the gate steps do not run
and the job passes, so non-releasing repos no longer need to pass
run-release: false (the skip escape hatch flagged in #674).

The run-release input is kept for backwards compatibility but is now
deprecated: passing false still suppresses the gate and emits a
::warning:: annotation pointing at the calling workflow. Removal is
tracked in #688.


## Documentation

- **describe dynamic cached-image tooling install**
CLAUDE.md claimed vergil-tooling CLI tools and validators are
pre-installed in the dev container images. The base images contain no
vergil-tooling; it is installed dynamically. Rewrite the Environment
Setup and Standard-Tooling Integration passages to describe the
per-branch cached-image mechanism (vrg-container-run builds
<base>:<tag>--<branch>--<hash> with the version pinned in vergil.toml,
cache keyed on lockfiles plus vergil.toml) and the CI-side dynamic
install via the actions/shared/setup/vergil action. Also fix the stale
actions/shared/setup/vergil-tooling path in the action list.

- **replace vrg-docker-run, fix v1.4 pin and pre-installed claim**
The docs-site and legacy development docs referenced the removed
vrg-docker-run command (renamed vrg-container-run), told users to
install vergil-tooling@v1.4 (the repo pins v2.1 in vergil.toml), and
claimed the dev-base container has every required tool pre-installed.
Static linters and docs tools are baked into the base image, but
vrg-validate itself arrives via the per-branch cached image that
vrg-container-run builds with the vergil.toml-pinned version.

Rename the command everywhere (including the CLI-reference link anchor
in workflows/index.md), bump the install snippet to v2.1, and rewrite
the validation and environment pages to distinguish baked-in tools from
the dynamically installed vergil-tooling, matching the corrected
CLAUDE.md description from #684.
