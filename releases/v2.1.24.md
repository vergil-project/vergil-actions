
# Release 2.1.24 (2026-08-12)

## Features

- **add shared/setup/build-command CI step (fail-closed, no retry) (#820)**
Add a composite action that runs a repo's declared [container].build-command
in CI, read through the vrg-container-build-command speller shipped in
vergil-tooling v2.1.189.

Unlike the sibling system-packages action (bounded apt retry), the build
command is fail-closed with NO retry: an arbitrary build command that fails is
a real failure, not a transient mirror flake. Logic lives in install.sh with a
self-contained behavioural harness (tests/install.test.sh) covering execute,
fail-closed-no-retry, and skip-when-undeclared.

Wired into ci-test.yml's unit job after system-packages (test-runtime
dependency only). Docs and mkdocs nav mirror the system-packages action.
