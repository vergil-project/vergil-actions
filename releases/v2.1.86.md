# Release 2.1.86 (2026-11-19)

## Bug fixes

- **remove early-exit pipes under pipefail and guard against them (#1326)**
  * fix(shell): remove early-exit pipes under pipefail and guard against them

  Under set -o pipefail, a consumer that exits on its first match (grep -q, grep -m, head) lets the producer die of SIGPIPE, so the pipeline fails although it matched. This failed release PR #1324's container-tag fixtures check.

  Every such site (38 lines in 17 files, two in action.yml run steps) now tests the producer's output with no pipe: a here-string for grep, find -print -quit for the semgrep detection, and a yq [...] | .[0] for the one head. scripts/bin/check-early-exit-pipes, run by validate-custom with its own tests, fails on reintroduction.
