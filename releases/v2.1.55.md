
# Release 2.1.55 (2026-10-23)

## Bug fixes

- **build every package cell on the matrix-recorded runtime and check it before signing (#1038)**
cd-release's package-build and ci-package's build pass each cell's matrix-recorded runtime to vrg-package build --runtime, through matrix.runtime || '' so a non-python cell passes an empty value, never null. package-sign now checks out the repo, installs vergil-tooling, downloads the package-manifest artifact and runs vrg-package check-runtime on the unsigned packages after rpm is installed and before signing, so a mixed-runtime release stops before anything is signed or tagged. Adds the package-runtime.test.sh harness to the cd-release smoke workflow and documents the runtime on the cd-release and ci-package pages. Needs vergil-tooling 2.1.262 (v2.1). Ref #1029
