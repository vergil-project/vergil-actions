
# Release 2.1.56 (2026-10-25)

## Bug fixes

- **match uv commands with global options in the uv pin guard (#1055)**
The uv pin guard in pin-python/tests/pin.test.sh matched only 'uv <subcommand>', so a global option before the subcommand (uv --quiet run, uv -q sync, uv --directory d run) hid the command from both the UV_PYTHON_PREFERENCE=only-system check and the detect.sh --no-config check. Both regexes now allow any run of global options (each optionally with one value) before the subcommand, and accept --no-config among the global options or among the bare flags right after the subcommand. uv tool, uv --version, comments and backtick prose stay exempt. Adds 13 fixtures both ways; no existing case changes result.
