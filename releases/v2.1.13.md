
# Release 2.1.13 (2026-07-09)

## Bug fixes

- **key first-release no-op off release tags, not missing main (#758)**
The version-divergence gate's first-release escape hatch guarded the wrong condition: it keyed off a missing origin/main. But the bootstrap wizard creates and pushes main at init, so main always exists on a brand-new repo, making the hatch unreachable. Every release-bearing repo's first PR into develop then hard-failed the gate with 'version not bumped: head (0.1.0) == main (0.1.0)' — there was no way to satisfy it, since nothing had been released.

Detect the first release from the real signal instead: the absence of a release tag. tag-and-release stamps every release with a vX.Y.Z tag, so no such tag means no release has occurred. This distinguishes the two EQUAL cases exactly — bootstrap (no tag) passes; a genuine missed bump after a prior release (tag exists) still fails — regardless of whether main exists. The fetch and compare steps now run only once a release exists.
