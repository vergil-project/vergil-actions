
# Release 2.1.38 (2026-10-06)

## Bug fixes

- **stop declaring signing secrets that shadow the package-signing environment (#913) (#914)**
The first packaged release (vergil-project/packages v1.1.0, CD run 37494464077) failed closed: package-sign saw an empty PACKAGE_SIGNING_KEY, although the package-signing environment was applied (deployment on main 16:17:57Z) and holds the secret. cd-release declared PACKAGE_SIGNING_KEY/PASSPHRASE under on.workflow_call.secrets (to satisfy actionlint), and a declared-but-unpassed secret shadowed the environment secret with an empty value.

Remove both declarations so the environment is the only source (matching publish-index, which declares none), and ignore actionlint's resulting undeclared-secret finding for exactly those two names in .github/actionlint.yaml. Document the rule.
