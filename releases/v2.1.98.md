# Release 2.1.98 (2026-11-25)

## Bug fixes

- **attach a missing CI evidence bundle on a re-run of a published release (#1440)**
  * fix(cd-release): attach a missing CI evidence bundle on a re-run of a published release

  A re-run of the release job after its tag exists skipped every evidence step and succeeded, leaving the release without its evidence bundle (vergil-fixture-ts-lib v0.1.10, CD run 45506188123). The job now checks the existing Release for both evidence assets: with them it skips the evidence steps; without them it gates, attests and attaches the bundle, enforced as on a new release; an unreadable Release fails the job. The tag and publish steps still run only on a new tag.
