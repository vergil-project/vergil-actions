
# Release 2.1.5 (2026-06-10)

## Bug fixes

- **pull from GHCR mirror with retry; bump to 0.71.0 (#706)**
The shared Trivy action pulled aquasec/trivy from Docker Hub anonymously with no retry, so transient Hub timeouts and anonymous rate limits turned the security/trivy check red on unrelated diffs (e.g. vergil-claude-plugin PR #475).

- Default the image to the GHCR mirror ghcr.io/aquasecurity/trivy, which sidesteps Docker Hub's anonymous pull rate limits entirely. GHCR is the natural registry from GitHub Actions runners and needs no Hub-token secret plumbed through consuming repos.
- Bump the default tag to 0.71.0 (released 2026-06-01) for freshness.
- Add a bounded pull-with-backoff step before the scan steps as a registry-agnostic backstop; subsequent docker run steps reuse the local image.
