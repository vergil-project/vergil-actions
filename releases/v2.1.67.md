
# Release 2.1.67 (2026-11-13)

## Bug fixes

- **give the github-config token Contents write so the audit can read merge settings (#1165)**
GitHub's Get a repository endpoint returns a repository's merge-related settings only to a token with Contents read and write (https://docs.github.com/en/rest/repos/repos#get-a-repository). With Contents read alone the fields are left out and the audit reports false drift. The audit itself writes no contents; the token stays scoped to the calling repository with Administration read. Ref vergil-project/vergil-actions#1164
