
# Release 2.1.39 (2026-10-07)

## Bug fixes

- **upload SARIF without accepted-suppressed results (#921)**
Code scanning ignores SARIF suppressions, so a finding the SARIF gate accepts (e.g. a justified nosemgrep) still failed GitHub's Semgrep OSS check. The Semgrep and Trivy actions now run vrg-sarif-filter and upload a filtered *.upload.sarif copy, while the unfiltered SARIF remains what the evidence job collects. The ci-security trivy job installs vergil-tooling to provide the filter. CodeQL is unchanged: analyze uploads internally. Docs updated. Requires a vergil-tooling release containing vrg-sarif-filter (vergil-project/vergil-tooling#3114). Ref #920


## Documentation

- **callers must pass secrets: inherit for environment secrets (#918) (#919)**
A controlled probe (vergil-project/packages#6, run 37507168545) proved that environment secrets reach a job in a cross-repo reusable workflow only when the caller passes secrets: inherit; an explicit map or nothing gives an empty value, and the callee's declaration is irrelevant. Correct the cd-release and publish-index caller docs and examples (inherit plus a scoped nosemgrep), and correct the #913 comments, which attributed the failure to secret shadowing (disproven).
