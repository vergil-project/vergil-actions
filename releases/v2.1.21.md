
# Release 2.1.21 (2026-08-05)

## Features

- **wire CONAN_AUDIT_PROVIDER_TOKEN_CONANCENTER into ci-audit workflow (#803)**
Declare the ConanCenter provider token as an optional workflow_call secret in ci-audit.yml and inject it into the dependency-audit step's env: so conan audit can authenticate inside the container. Threaded via the explicit-secret chain (never secrets: inherit, per epics #189/#197).

The token is cpp-only; when the caller leaves it unset the cpp audit path skips the conan gate with a notice rather than failing auth. Documents the caller-side secret passing for cpp repos in the workflows README and ci-audit docs page.
