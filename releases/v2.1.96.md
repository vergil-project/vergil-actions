# Release 2.1.96 (2026-11-24)

## Bug fixes

- **declare upstream-refresh's App keys optional and check them in the jobs that read them (#1429)**
  * test(workflows): fail a required workflow_call secret with a job that declares no environment

  check-secret-environments now names each job of a reusable workflow that declares a secret required: true while the job names no environment. GitHub refuses such a call when the secret exists only in an environment. It catches ops-upstream-refresh.yml's prepare job (#1428).

  * fix(workflows): declare upstream-refresh's App keys optional and check them in the jobs that read them

  prepare holds no keys and declares no environment, so required keys kept only in the automation environment made GitHub refuse the call before prepare started. publish and report now fail loudly, naming each missing secret, before they use the keys; nothing falls back to GITHUB_TOKEN (#1428).
