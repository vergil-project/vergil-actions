
# Release 2.1.49 (2026-10-22)

## CI

- **pin Python legs to the image's interpreter with UV_PYTHON_PREFERENCE=only-system (#995)**
* ci(toolchain): pin Python legs to the image's interpreter with UV_PYTHON_PREFERENCE=only-system

Every Python matrix leg (ci-quality lint and typecheck, ci-audit dependencies, ci-test unit) now pins uv through a new ci/toolchain/pin-python action, which exports UV_PYTHON=<x.y> and UV_PYTHON_PREFERENCE=only-system. A repo's uv python-preference (e.g. only-managed) can no longer make a leg download a managed Python instead of using the image's; a missing interpreter fails loudly. The pin.test.sh harness also checks that every job with an assert-toolchain step pins through the action and that no workflow sets UV_PYTHON by hand. assert-toolchain now logs the interpreter path it found. Ref vergil-project/vergil-actions#994
