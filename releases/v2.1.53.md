
# Release 2.1.53 (2026-10-23)

## Bug fixes

- **derive the release image suffix from the resolver (#1030)**
The release job built its image suffix from the caller's container-suffix, else language, else base, so a C++ caller passing language: cpp got the unpublished prod-cpp image. The setup job now runs the new cd/release/primary-suffix action on the shared setup action's primary-version and container-suffixes, and the release job runs on prod-<container-suffixes[primary]>:<primary-container-tag>, the image CI's primary leg uses (clang-20 -> prod-cpp-clang:20). The caller's container-suffix is kept only as a cross-check that must equal the resolved primary suffix; a mismatch fails setup. container-tag.test.sh gains structure checks for the suffix wiring and fixture cases for C++ (clang-20), TypeScript (node-24), Python with a matching caller suffix, and three mismatched-suffix failures. Ref #1020
