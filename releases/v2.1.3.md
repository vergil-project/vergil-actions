
# Release 2.1.3 (2026-06-06)

## Bug fixes

- **grant actions: read and add upload-sarif artifact fallback (#694)**
SARIF upload to code scanning fails on private consumer repos because
codeql-action/upload-sarif reads the workflow run via the Actions API,
which needs actions: read there; public repos do not, so the gap was
invisible on vergil-project repos.

- Add actions: read at the workflow level and to the codeql, trivy,
  and semgrep job permissions in ci-security.yml, and to this repo's
  own caller in ci.yml.
- Add an upload-sarif input (default true) to ci-security.yml and to
  the trivy and semgrep actions. When false, scans still run and still
  fail on findings, but SARIF results are attached as build artifacts
  (trivy-fs-sarif, semgrep-sarif) instead of being uploaded to code
  scanning — the documented posture for private repos without GHAS.
- Gate the codeql job on upload-sarif: CodeQL cannot run on private
  repos without GHAS regardless of upload destination.
- Document the permission and the no-GHAS configuration across the
  workflow, action, and CI-gates docs.
