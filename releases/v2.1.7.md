
# Release 2.1.7 (2026-07-01)

## Bug fixes

- **name release job "release / release" to match confirm-main gate (#720)**
vergil-tooling's confirm-main stage (hardened under #1853) matches the CD release job name EXACTLY against "release / release" and fails closed on any other name. This repo runs a reduced inline release job (freeze-refs + tag-and-release; no registry publish, as an actions-only library) whose display name was "cd / release" — a designed convention (see the CD-checks table in the 2026-05-09 workflow-convention spec, where CD checks were informational, not enforced).

The floating v2.1 tooling pin adopted the tightened gate silently between the 2.1.5 release (passed) and 2.1.6 (stalled at confirm-main, leaving a half-applied release and open tracking issue #715).

Rename the job's display label to "release / release" to match the tooling and align with the sibling docs job, which already surfaces as "docs / docs". The inline job's steps are unchanged. Update the spec's CD-checks table entry to keep docs consistent with the code.
