
# Release 2.1.27 (2026-08-12)

## Bug fixes

- **bridge per-matrix report files into test/audit/quality evidence artifacts (#837)**
In GitHub Actions each job runs on its own runner with its own filesystem. The test/audit/quality exec (matrix) jobs produced their report files, but the separate evidence job did a clean checkout and called evidence/emit against globs that matched an empty tree, stranding every report and shipping empty payloads for those three gates while only security carried real files. Mirror the working ci-security.yml pattern: each matrix leg uploads its version-suffixed reports as a per-version partial artifact, and the evidence job downloads every leg's partials (merge-multiple) before emit, so the bundle carries each interpreter version's reports. quality-ruff.json / quality-mypy.xml are a locked filename contract with vergil-tooling#2811 and stay skipped-empty (non-fatal) until it releases.
