
# Release 2.1.43 (2026-10-19)

## Bug fixes

- **set NO_MKDOCS_2_WARNING to silence the MkDocs 2.0 banner (#948)**
mkdocs-material 9.7.x prints a MkDocs 2.0 warning banner on every build unless NO_MKDOCS_2_WARNING is set. A caller's env does not reach a reusable workflow, so set it on the ci-docs Build docs step and the cd-docs Deploy docs step, which are the only places mkdocs and mike run. Ref #947
