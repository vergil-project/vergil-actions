
# Release 2.1.8 (2026-07-01)

## Features

- **add reusable cd-docs-refresh workflow (#726)**
Org documentation-site repos publish generated roadmap/activity pages that
change with epic activity, not with any release of the docs repo — so there is
no push or release event to rebuild on. They need a scheduled + on-demand job
that regenerates the pages and republishes the site.

Add cd-docs-refresh.yml, a reusable workflow that wraps cd-docs.yml with the
page generation pre-wired as its pre-deploy-command default (vrg-roadmap /
vrg-activity-log). Every org's docs repo drives it from a thin caller
(on: schedule + workflow_dispatch), rather than duplicating the generation
command. Reusing cd-docs.yml inherits the full deploy path, including the
un-versioned single-site deploy from #713.
