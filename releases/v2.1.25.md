
# Release 2.1.25 (2026-08-12)

## Features

- **export NODE_PATH in the build-command step for CI resolution parity (#825)**
After the declared [container].build-command runs, export NODE_PATH (the npm
global root from `npm root -g`) to $GITHUB_ENV so subsequent CI test steps can
resolve a node library baked out-of-workspace by the build-command (npm install
-g <lib>) via CommonJS require. This mirrors the NODE_PATH the local dev image
injects (vergil-project/vergil-tooling#2781), keeping baked-library resolution
identical locally and in CI — the drift epic vergil-project/.github#291 prevents.

The export is guarded on CI context ($GITHUB_ENV present) and npm being on PATH,
so a non-CI or non-node run is a clean no-op; the step stays fail-closed and
retry-free. NODE_PATH is honoured by require only (ESM import ignores it).

Extends the install.test.sh harness with two cases (NODE_PATH appended when a
command ran with a stub npm on PATH; nothing appended on the skip path) and
documents the behavior and the require-only caveat.
