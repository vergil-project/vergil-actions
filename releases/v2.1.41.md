
# Release 2.1.41 (2026-10-08)

## Bug fixes

- **Azure-first apt mirror list, fail-fast apt and job timeouts for package jobs (#933)**
* fix(package): use the Azure apt mirror and fail-fast apt in package setup

Move the package setup OS-prerequisites step into os-prereqs.sh. On x86_64 Ubuntu containers it points the archive and security URIs (deb822 ubuntu.sources and legacy sources.list) at http://azure.archive.ubuntu.com/ubuntu/, the mirror GitHub's hosted runners use, before the single apt-get update; arm64 (ports.ubuntu.com) is left untouched. It writes /etc/apt/apt.conf.d/80-vergil-fast-fail (3 retries, 20 s timeouts) for every later apt call in the job, installs all prerequisites including gnupg in one call, and on UBI runs one dnf install with retries=3/timeout=20 and path-form curl/gpg. Adds tests/os-prereqs.test.sh, wired into the smoke workflow, and documents the action. Ref #931

* fix(package): mark os-prereqs.sh executable like detect.sh


## Features

- **tier the package matrix: reduced on feature PRs, full on release PRs (#932)**
Add an optional package-tier input (auto|full|reduced). In auto, release PRs (release/* into main) and non-PR events run the full matrix; other PRs run the reduced matrix. The tier is passed to vrg-package matrix --tier and recorded as metrics.tier in the package evidence. Requires a vergil-tooling release with --tier. Ref #930
