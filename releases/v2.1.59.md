
# Release 2.1.59 (2026-10-26)

## Bug fixes

- **retry a scan that errors without a report and report it as a scan error (#1080)**
The fs and image scans now run through scan.sh, which tells a scan with findings apart from one that wrote no report. A no-report scan is retried with backoff and then fails with a 'Trivy scan errored (no report produced)' message instead of being reported as vulnerabilities; it never passes. The action exposes the outcome as a result output (passed, findings, error) and skips the SARIF upload when there is no report. tests/scan.test.sh covers the outcomes with a stubbed docker.
