
# Release 2.1.71 (2026-11-14)

## CI

- **run github-config as the automation identity with vrg-github-repo-config update (#1156) (#1186)**
The github-config job now runs update instead of audit, as the org automation App named by the VRG_AUTOMATION_APP org variable. Its token is scoped to Administration, Contents, Pull requests and Workflows write plus Metadata read. A first step, before any token is minted, fails the job unless it runs from refs/heads/develop and VRG_AUTOMATION_APP is set, and the checkout pins develop. The git identity is set to the App's bot user. The temporary bypass-probe job is removed, and the docs describe the new job. Ref vergil-project/vergil-actions#1156

- **cap the github-config job at 60 minutes (#1188)**
The automation App token has a fixed one-hour life and update's merge wait ends inside it, so a longer run cannot use its token. GitHub's 360-minute default would let a hung run hold the concurrency group for six hours. Ref #1187.
