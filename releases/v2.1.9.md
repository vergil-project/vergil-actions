
# Release 2.1.9 (2026-07-01)

## Chores

- **ignore .vergil/ tooling scratch dir (#731)**
The .vergil/ scratch dir (pr-workflow.json, vrg-validate/finalize logs) was untracked and unignored here, so every worktree read dirty via git status --porcelain. That tripped the removable gate in vrg-worktree-status and vrg-finalize-pr, leaving merged worktrees unreapable. Aligns vergil-actions with the rest of the fleet, which already ignores it. Ref #730.


## Features

- **add reusable ops-epic-rollup workflow (#733)**
Add ops-epic-rollup.yml, a reusable workflow that runs vrg-epic-rollup for a just-closed task's parent epic. Fires via a thin on: issues.closed caller (per repo convention), mirroring the ops-github-config App-token pattern.

Parameterizes the epic repo (default .github) and the App token so it works across all three orgs: the token is scoped to the caller repo plus the epic repo, and each org's caller passes its own APP_CLIENT_ID / APP_PRIVATE_KEY secrets. The cross-repo epic close stays our code, not a keyword, since epics live in a different repo than tasks.

Part of epic vergil-project/.github#75. Refs vergil-project/vergil-tooling#2042 (vrg-epic-rollup CLI), vergil-project/vergil-tooling#2052 (thin caller).
