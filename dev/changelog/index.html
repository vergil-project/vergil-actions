    Changelog¶

    All notable changes to this project will be documented in this file.

    The format is based on Keep a Changelog and this project adheres to Semantic Versioning.

    [2.1.18] - 2026-07-24¶

    Documentation¶

    • explicit CD secrets and semgrep rule-exclusion docs (#788)

    [2.1.17] - 2026-07-13¶

    Refactoring¶

    • share one harvest across evidence gate and attach (#782)

    [2.1.16] - 2026-07-13¶

    Bug fixes¶

    • split cd-release evidence into pre-publish gate + post-release attach (#777)

    [2.1.15] - 2026-07-13¶

    Bug fixes¶

    • pass GH_TOKEN to the docs stage step so evidence links resolve (#772)

    Features¶

    • harvest, attest, and attach CI evidence (warning mode) (#771)

    [2.1.14] - 2026-07-13¶

    Documentation¶

    • codify the all-hard-gates principle (#765)

    Features¶

    • emit ci-evidence- artifacts from gate workflows (#764)

    [2.1.13] - 2026-07-09¶

    Bug fixes¶

    • key first-release no-op off release tags, not missing main (#758)

    [2.1.12] - 2026-07-07¶

    Bug fixes¶

    • fully-qualify the nested cd-docs reusable ref (#751) (#752)

    [2.1.11] - 2026-07-04¶

    Chores¶

    • retire standards-compliance linkage gate (#747)

    [2.1.10] - 2026-07-02¶

    CI¶

    • add on: issues.closed caller for event-driven epic rollup (#738)

    Chores¶

    • relicense to MIT (#740)

    Features¶

    • add reusable ops-epic-sweep reconciliation workflow (#742)

    [2.1.9] - 2026-07-01¶

    Chores¶

    • ignore .vergil/ tooling scratch dir (#731)

    Features¶

    • add reusable ops-epic-rollup workflow (#733)

    [2.1.8] - 2026-07-01¶

    Features¶

    • add reusable cd-docs-refresh workflow (#726)

    [2.1.7] - 2026-07-01¶

    Bug fixes¶

    • name release job "release / release" to match confirm-main gate (#720)

    [2.1.6] - 2026-07-01¶

    Bug fixes¶

    • deploy un-versioned site when versioning-scheme=none (#714)

    Chores¶

    • point plugin marketplace at main (single released channel, #45) (#712)

    [2.1.5] - 2026-06-10¶

    Bug fixes¶

    • pull from GHCR mirror with retry; bump to 0.71.0 (#706)

    [2.1.4] - 2026-06-06¶

    Documentation¶

    • document the actions: read caller contract and rollout policy (#701)

    [2.1.3] - 2026-06-06¶

    Bug fixes¶

    • grant actions: read and add upload-sarif artifact fallback (#694)

    [2.1.2] - 2026-06-05¶

    Bug fixes¶

    • gate follows release-model instead of run-release wiring

    Documentation¶

    • describe dynamic cached-image tooling install
    • replace vrg-docker-run, fix v1.4 pin and pre-installed claim

    [2.1.1] - 2026-06-04¶

    Bug fixes¶

    • track @develop for standards-compliance setup ref (#679)

    Chores¶

    • bump vergil pin to v2.1 (#679)

    Documentation¶

    • add v2.0→v2.1 canary design (#679)
    • revise v2.0→v2.1 canary design after pushback (#679)
    • drop unneeded VERSION bump from canary design (#679)
    • expand canary doc scope to full @v2.0 sweep (#679)
    • add v2.0→v2.1 canary implementation plan (#679)
    • note no-auto-close-keyword PR constraint (#679)
    • bump consumer @v2.0 references to v2.1 (#679)

    [2.1.0] - 2026-06-04¶

    Bug fixes¶

    • treat missing origin/main as a first-release no-op

    [2.0.28] - 2026-06-02¶

    CI¶

    • add build-only docs verification to PR CI

    [2.0.27] - 2026-06-01¶

    Bug fixes¶

    • run codeql on bare runner so autobuild has a language toolchain

    [2.0.26] - 2026-05-28¶

    Bug fixes¶

    • separate language and container-suffix inputs in cd-release.yml

    [2.0.25] - 2026-05-28¶

    Bug fixes¶

    • revert to Docker-based approach for bare-runner compatibility

    [2.0.24] - 2026-05-28¶

    Bug fixes¶

    • install uv via setup-uv when not present on bare runners
    • use astral-sh/setup-uv@v7 (v8 has no rolling major tag)
    • use pip to install uv on bare runners instead of astral-sh/setup-uv

    [2.0.23] - 2026-05-28¶

    Bug fixes¶

    • run codeql job in container image

    [2.0.22] - 2026-05-28¶

    Bug fixes¶

    • resolve v2.0.21 breaking changes in release and trivy workflows

    [2.0.21] - 2026-05-27¶

    Bug fixes¶

    • handle missing primary-language in vergil.toml
    • revert internal refs to @develop and replace trivy shell with vrg-trivy-scan
    • use local action paths for true self-referencing CI
    • run trivy job in prod-base container
    • revert trivy action to original inline Docker approach
    • use dev container prefix for CI
    • eliminate shell injection patterns in action YAML files
    • replace Docker orchestration with vrg-trivy-scan direct invocation

    Chores¶

    • remove invalid primary-language from vergil.toml
    • remove deprecated version-bump-pr action

    Refactoring¶

    • replace inline shell with vrg-semgrep-scan
    • replace inline SARIF evaluation with vrg-sarif-evaluate
    • replace inlined Python scripts with vrg-docs-stage and vrg-docs-patch-nav
    • replace case-statement command derivation with vrg-ecosystem-resolve
    • replace inline validation with vrg-release-validate-inputs
